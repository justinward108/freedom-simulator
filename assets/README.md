# Images

Put game images here. Everything in this folder is copied into the deploy except this README.

| Folder | For |
| --- | --- |
| `units/` | Infantry, air wing and fleet art |
| `structures/` | AA guns, forts, batteries, factories and the rest |
| `regions/` | Region or map art, including the real-looking map |
| `ui/` | Backgrounds, logos, buttons |

Reference them from the page with relative paths, e.g. `assets/units/infantry.png`.
Keep file names lowercase with hyphens. PNG or WebP for art, SVG for icons.
